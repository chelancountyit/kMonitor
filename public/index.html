      1. Embed JS Heartbeat Snippet in Your Kiosk Web App

      Add this single script tag to your kiosk web application's HTML. It sends a heartbeat every 5 seconds over WebSocket (with HTTP POST fallback) along with current URL, memory usage, and uptime.

      Tip for shared web apps: If all kiosks load the exact same web app code, you only need to add <script src=".../kiosk-heartbeat.js"></script> once without hardcoding data-kiosk-id. Then launch each kiosk browser with ?kioskId=kiosk-01 etc. in its startup URL—the script automatically saves its ID in localStorage across page navigations!
